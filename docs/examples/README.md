# A draft mined from an open-source repository

[`change-cache-backend-api/SKILL.md`](change-cache-backend-api/SKILL.md) is a draft skill
TeamHandbook wrote from the history of [django/django](https://github.com/django/django),
read up to commit
[`50eef95`](https://github.com/django/django/commit/50eef95591b1e5d8c47b2e8c96066cb0c516753a)
on `main` (2026-09-30). Nothing in it has been edited since it passed the format check.

The work it describes is one that history keeps repeating: a change to the cache API made
in the base class and in every cache backend module at once, usually with the cache
documentation beside them, by several contributors over the years. `/handbook:mine` run in
a clone at that commit still finds it.

What the draft carries:

- **A skeleton of the steps**, in the order the past changes took them.
- **A file map the history measured**: which files the work touched, and in how many of
  the past changes it was written from.
- **Mistakes the history shows**, each pointing at the past change it came from. `#1`
  and `#2` stand in for those changes' ticket numbers and commit hashes, which are replaced
  before anything reaches the model.

What it is not: a finished skill. It was written by an earlier version of the drafter,
before each step cited its evidence and before a draft ended on a list of what the history
could not show. Drafts are asked for both now, and the one the guided demo uses has them
([`demo/recorded-draft.md`](../../demo/recorded-draft.md)).

It was screened before it was placed here, and nothing was found: no secret, no trace of
the machine it was written on, no contributor's name.
